## Guestbook

A digital guestbook built while learning Vue, letting visitors leave their name and a message, displayed with the date.

### About

This project is a digital guestbook developed while learning Vue, Node.js, and TypeScript. Visitors can submit their name and a message, which is recorded along with the sending date and displayed on the page. It’s ideal for blogs, personal websites, events, or any platform that wants to keep a record of visitor feedback. The project provided practice with Vue fundamentals, including data binding, event handling, reactive display of submitted messages, as well as backend handling with Node.js and type safety using TypeScript.

### Installation

1. Install dependencies for the backend
```bash
cd api
npm install
```

2. Start the backend server
```bash
npm run dev
```

3. Install dependencies for the frontend
```bash
cd web
npm install
```

3. Install dependencies for the frontend
```bash
npm run dev
```
